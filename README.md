# Data Life Learning Centre — платформа публикации уроков

Flask + SQLite3. Запуск одним файлом.

## Установка и запуск

```bash
pip install -r requirements.txt
python run.py
```

Сайт откроется на `http://127.0.0.1:5000`.

При **первом запуске** автоматически создаётся:
- база данных `instance/app.db`
- аккаунт администратора (логин `admin`, случайный пароль — он будет
  напечатан в консоли один раз, сохраните его)

## Роли

- **Администратор / преподаватель** — полный доступ: создаёт пользователей,
  создаёт уроки, загружает файлы теории и домашнего задания, открывает
  доступ к урокам конкретным ученикам, видит все сданные работы.
- **Ученик** — только чтение: видит только те уроки, к которым ему открыт
  доступ, может скачивать файлы урока и отправлять свою домашнюю работу
  (файл + комментарий). Регистрации на сайте нет — логин и пароль ученику
  выдаёт администратор.

## Структура

```
run.py                     запуск приложения
app/
  __init__.py               фабрика Flask-приложения
  db.py                      схема SQLite3, инициализация базы
  auth.py                    вход / выход
  routes_admin.py            панель преподавателя
  routes_student.py          кабинет ученика
  utils.py                   декораторы доступа, работа с файлами
  templates/                 HTML-шаблоны
  static/css/style.css       стили
instance/
  app.db                     база данных (создаётся автоматически)
  secret.key                 ключ сессии (создаётся автоматически)
  uploads/lessons/<id>/      файлы уроков (теория, домашка от преподавателя)
  uploads/submissions/<id>/<user_id>/   сданные работы учеников
```

## Заметки по безопасности перед публикацией в интернет

- Смените пароль `admin` сразу после первого входа (или создайте себе
  именной аккаунт и удалите `admin`).
- `instance/` содержит базу данных, ключ сессии и все загруженные файлы —
  не публикуйте эту папку и добавьте её в `.gitignore`.
- Для реальной эксплуатации в интернете запускайте через WSGI-сервер
  (gunicorn/waitress) за HTTPS, а не встроенный dev-сервер Flask.
